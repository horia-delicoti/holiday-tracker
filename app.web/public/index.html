Currencies & default rates

Rate = how many units of the base currency one unit is worth (EUR 0.85 means €1 = £0.85). These are defaults for the entry form only. Each line item stores the rate it was entered with, so changing a rate here never restates a past trip.
The currency list comes from your device, not the internet — every name and symbol above is one your browser already knows, so this works offline. Rates are yours: Update rates online fills the ones the European Central Bank publishes and is the only outbound request this app ever makes; the rest you type when they drift enough to matter.

Restore a snapshot

One snapshot is written automatically before every change; the newest 30 are kept. Restoring snapshots the current state first, so a restore is itself undoable.
